# Rohit Singh Portfolio

A personal portfolio for Rohit Singh, Senior Analytics Engineer.

The first version is built as an operating brief rather than a generic resume
page: it highlights analytics engineering impact, decision models, pipeline
automation, selected systems, technical depth, and certifications.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/`.

## Build

```bash
npm run build
```

## Project Notes

- Branch: `development`
- Framework: Next.js through vinext
- Primary files: `app/page.tsx`, `app/globals.css`, `app/layout.tsx`
